# STM32 大作业

本项目为小组大作业仓库，主要包含基于 STM32F103 的硬件控制代码以及机械夹爪模型的设计与报告文档。

为了保证团队协作的顺畅，请所有组员在参与开发前仔细阅读以下内容。

## 📁 项目结构

```text
├── Core/               # 核心代码（含步进电机代码实现）
├── Drivers/            # 硬件驱动（含双舵机硬件代码实现）
├── bsp/                # 板级支持包及报告筹备
├── Reports/            # 报告与文档（含机械组-夹爪模型第一版）
├── .mxproject          # STM32CubeMX 工程配置文件
├── Major_assignment.ioc# STM32CubeMX 工程文件
├── Makefile            # 编译脚本
└── startup_stm32f103xb.s # 启动文件

##注意事项
1. 不熟悉操作的同学，先在 `testbench` 分支练习和测试；熟悉流程、确认修改无误后，再将内容合并到 `main` 分支。
2. 所有非代码操作均在 `report` 文件夹下进行。
3. 所有非 OB 笔记文件（如 ZIP 压缩包等）统一放在 `report/asset` 文件夹中。
